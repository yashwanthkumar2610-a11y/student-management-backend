Student Management System — Backend

This project provides the backend services for a Student Management System using Node.js, Express.js, and MySQL.

Technologies Used

- Node.js
- Express.js
- MySQL
- REST API

Features

- Add student records
- View all students
- Update student details
- Delete student records
- Store student information in MySQL

Installation and Setup

1. Install Node.js and MySQL.
2. Clone or download this repository.
3. Open the backend folder in a terminal.
4. Run "npm install".
5. Configure the MySQL connection using your local environment variables.
6. Run "npm start".

The backend server uses port 5000 by default.

Security

Database credentials should be stored locally and must not be committed to GitHub. Do not upload ".env" files.

Project Status

Core student management operations are implemented and tested locally.
